Retail Credit Risk & Portfolio Optimization Case Study

Project Overview
This data analyst project optimizes credit risk strategies and evaluates retail portfolio health using a consumer lending database of over 2 million accounts. The dashboard isolates early warning indicators (EWIs) of defaults, evaluates asset concentration, and applies built-in AI diagnostics to identify factors that mitigate loan defaults.

Core Business & Strategic Insights

a.	Risk-Adjusted Volume Anchor: The dual-axis stability engine confirms that "Veteran (10+ Years)" employment tiers anchor the portfolio's highest capital volume while maintaining structural loan performance stability.
b.	Prior Default Exposure: Data segmentation highlights that applicants with a history of prior public records double the baseline default probability of the portfolio.
c.	AI Root-Cause Diagnosis: Integrated built-in Key Influencer regression engines to systematically map demographic and behavioural features (like homeownership types and loan purposes) that actively influence default metrics to decrease.

Technical Workspace Implementation

a.	Data Pipelines (Python):  Developed automated Pandas cleaning scripts to process millions of transaction rows, eliminate columns missing >80% of data, and map categorical fields into structured binary risk identifiers.
b.	BI Architecture (Power BI): Aggregated metrics into a zero-lag data structure to deploy an executive-ready dark mode dashboard featuring dynamic decomposition trees, custom groupings, and risk funnel profiling.
